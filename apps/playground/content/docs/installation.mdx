## Requirements

- React 19
- Tailwind CSS 4

## Install the package

<InstallCommand packages="@rax-ds/ui" />

`@rax-ds/tokens` is installed automatically.

## Import the styles

Add two lines to your global CSS file. Import Tailwind first, then the design system:

```css
@import 'tailwindcss';
@import '@rax-ds/ui/styles.css';
```

The second line brings in the design tokens and tells Tailwind where to find the component classes, so no `@source` rule is needed.

## Use a component

```tsx
import { Button } from '@rax-ds/ui';

export function SaveButton() {
    return <Button>Save</Button>;
}
```

Components that need the browser are marked `'use client'` inside the package, so you can render all of them from a Server Component.
