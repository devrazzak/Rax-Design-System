## Requirements

- React 19
- Tailwind CSS 4

## Install

<InstallCommand packages="@rax-ds/ui" />

## Import the styles

Import Tailwind first, then the design system styles, in your global CSS file:

```css
@import 'tailwindcss';
@import '@rax-ds/ui/styles.css';
```

The full guide is written in a later step.
