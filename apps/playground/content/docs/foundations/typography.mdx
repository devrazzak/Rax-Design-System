## Font families

| Token                    | Tailwind    | Default                                          |
| ------------------------ | ----------- | ------------------------------------------------ |
| `--rax-font-family-sans` | `font-sans` | `Inter, ui-sans-serif, system-ui, sans-serif`    |
| `--rax-font-family-mono` | `font-mono` | `ui-monospace, SFMono-Regular, Menlo, monospace` |

The package does not load a font file. Load Inter yourself (for example with `next/font`) or override `--rax-font-family-sans` with your own font.
