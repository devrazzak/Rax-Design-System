## Overview

Components use semantic color tokens, never raw palette values. Each token is a CSS variable named `--rax-color-<name>` and a Tailwind color named `<name>`, so `--rax-color-primary` is used as `bg-primary` or `text-primary`.

The swatches below read the live variables. Switch the theme to see the dark values.
