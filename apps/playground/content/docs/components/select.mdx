## Usage

```tsx
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@rax-ds/ui';

export function StatusSelect() {
    return (
        <Select>
            <SelectTrigger aria-label="Status">
                <SelectValue placeholder="Select a status" />
            </SelectTrigger>
            <SelectContent>
                <SelectItem value="pending">Pending</SelectItem>
                <SelectItem value="shipped">Shipped</SelectItem>
            </SelectContent>
        </Select>
    );
}
```

To build a list from an array of options, use [OptionSelect](/docs/components/option-select).

## Accessibility

- Built on the Radix Select. The trigger is a button with `role="combobox"`, and the list is a `listbox` of options.
- `Enter`, `Space` or `ArrowDown` on the trigger opens the list. `ArrowUp` and `ArrowDown` move between items, `Enter` or `Space` selects, and `Escape` closes. Typing a letter jumps to a matching item.
- Give the trigger an accessible name with a [Label](/docs/components/label) (`htmlFor` and `id` on the trigger) or `aria-label`.
- `aria-invalid` on the trigger turns the border red.
