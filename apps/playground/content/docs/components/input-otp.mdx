## Usage

```tsx
import { InputOTP, InputOTPGroup, InputOTPSlot } from '@rax-ds/ui';

export function CodeInput() {
    return (
        <InputOTP maxLength={4} aria-label="Verification code">
            <InputOTPGroup>
                <InputOTPSlot index={0} />
                <InputOTPSlot index={1} />
                <InputOTPSlot index={2} />
                <InputOTPSlot index={3} />
            </InputOTPGroup>
        </InputOTP>
    );
}
```

`InputOTPSeparator` adds a dash between groups. Only the `children` form is supported, not `render`. Built on the `input-otp` library.

## Accessibility

- One real `<input>` receives the typing, and the slots only display its characters. Typing, deleting, pasting and the browser's autofill work on that input.
- Give it an accessible name with `aria-label` or a [Label](/docs/components/label) with `htmlFor` and `id`.
- `aria-invalid` and `disabled` on the input change the look of all slots.
