## Usage

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from '@rax-ds/ui';

export function Faq() {
    return (
        <Accordion type="single" collapsible>
            <AccordionItem value="returns">
                <AccordionTrigger>Can I return an item?</AccordionTrigger>
                <AccordionContent>Yes, within 30 days of delivery.</AccordionContent>
            </AccordionItem>
        </Accordion>
    );
}
```

`type` is required. Set `size` once on `Accordion`, and every item follows.

## Accessibility

- Built on the Radix Accordion. Each trigger is a button inside a heading, with `aria-expanded` and `aria-controls` pointing to its panel.
- `Enter` and `Space` open or close the focused item. `ArrowDown` and `ArrowUp` move focus between triggers, and `Home` and `End` jump to the first and the last.
- The trigger text is the accessible name of the section, so make it describe the content.
