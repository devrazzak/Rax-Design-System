## Usage

```tsx
import { SearchIcon } from 'lucide-react';

import { InputGroup, InputGroupAddon, InputGroupInput } from '@rax-ds/ui';

export function SearchField() {
    return (
        <InputGroup>
            <InputGroupAddon>
                <SearchIcon />
            </InputGroupAddon>
            <InputGroupInput placeholder="Search" aria-label="Search" />
        </InputGroup>
    );
}
```

The group is one box that owns the border and the focus ring. Use `InputGroupInput` inside it, not [Input](/docs/components/input).

## Accessibility

- The input is a native `<input>`. Give it a label with `htmlFor` and `id`, or `aria-label`.
- Addons are plain elements. Text in an addon is not a label of the input.
- `disabled` and `aria-invalid` on the input style the whole group.
