## Usage

```tsx
import { BoldIcon } from 'lucide-react';

import { Toggle } from '@rax-ds/ui';

export function BoldToggle() {
    return (
        <Toggle aria-label="Toggle bold">
            <BoldIcon />
        </Toggle>
    );
}
```

For several related toggles use [ToggleGroup](/docs/components/toggle-group).

## Accessibility

- Built on the Radix Toggle. It is a button with `aria-pressed` that reflects the state.
- `Space` and `Enter` toggle it.
- An icon-only toggle needs `aria-label`.
