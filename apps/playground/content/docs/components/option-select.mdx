## Usage

```tsx
import { OptionSelect } from '@rax-ds/ui';

const options = [
    { value: 'pending', label: 'Pending' },
    { value: 'shipped', label: 'Shipped' },
];

export function StatusSelect() {
    return <OptionSelect options={options} placeholder="Select a status" aria-label="Status" />;
}
```

OptionSelect is a [Select](/docs/components/select) built from an `options` array. For groups or custom items, use the Select parts directly.

## Accessibility

- It renders a [Select](/docs/components/select), so it has the same Radix keyboard behavior and roles.
- `id`, `aria-label`, `aria-labelledby`, `aria-describedby` and `aria-invalid` go to the trigger. Give it an accessible name with one of them or a [Label](/docs/components/label).
