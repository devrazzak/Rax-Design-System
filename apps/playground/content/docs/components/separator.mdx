```tsx
    return (
        <>
            <Text>Profile</Text>
            <Separator />

        </>
    );
}
```

## Accessibility

- Built on the Radix Separator. A decorative separator (the default) gets `role="none"`, so screen readers skip it.
- With `decorative={false}` it gets `role="separator"`, and `aria-orientation="vertical"` when vertical.
