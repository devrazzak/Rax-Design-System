## Usage

```tsx
import { Field, FieldLabel, RadioGroup, RadioGroupItem } from '@rax-ds/ui';

export function DeliveryMethod() {
    return (
        <RadioGroup defaultValue="standard" aria-label="Delivery method">
            <Field orientation="horizontal">
                <RadioGroupItem value="standard" id="standard" />
                <FieldLabel htmlFor="standard">Standard shipping</FieldLabel>
            </Field>
            <Field orientation="horizontal">
                <RadioGroupItem value="express" id="express" />
                <FieldLabel htmlFor="express">Express shipping</FieldLabel>
            </Field>
        </RadioGroup>
    );
}
```

## Accessibility

- Built on the Radix Radio Group. The group has `role="radiogroup"` and the items have `role="radio"`.
- `Tab` moves focus into the group, and the arrow keys move between items and select them. `Space` selects the focused item.
- Give the group an accessible name with `aria-label`, or a `FieldLegend` inside a `FieldSet`, and give each item a label with `htmlFor` and `id`.
