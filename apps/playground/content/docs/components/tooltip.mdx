## Usage

```tsx
import { Button, Tooltip, TooltipContent, TooltipTrigger } from '@rax-ds/ui';

export function SaveButton() {
    return (
        <Tooltip>
            <TooltipTrigger asChild>
                <Button>Save</Button>
            </TooltipTrigger>
            <TooltipContent>Save your changes</TooltipContent>
        </Tooltip>
    );
}
```

Every `Tooltip` brings its own provider, with no delay, so you do not need a `TooltipProvider` at the root. A provider higher up in the tree is ignored. To change the delay, set `delayDuration` on the `Tooltip`.

A tooltip is for a short text hint. Do not put interactive content in it. Use [Popover](/docs/components/popover) for that.

## Accessibility

- Built on the Radix Tooltip. The tooltip opens on hover and on keyboard focus of the trigger, and `Escape` closes it.
- The trigger is described by the tooltip content through `aria-describedby`, and the content has `role="tooltip"`.
- Touch devices do not show tooltips on hover, so do not hide essential information in one. An icon-only control still needs its own accessible name.

### Other parts

`TooltipTrigger` takes the props of its Radix part, and `asChild` lets it use your own element. `TooltipProvider` is exported and sets `delayDuration` to 0 by default, but `Tooltip` does not use a provider from higher up.
