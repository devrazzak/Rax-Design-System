## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from '@rax-ds/ui';

export function UserAvatar() {
    return (
        <Avatar>
            <AvatarImage src="/photos/alex.png" alt="Alex Morgan" />
            <AvatarFallback>AM</AvatarFallback>
        </Avatar>
    );
}
```

## Accessibility

- Built on the Radix Avatar. The image is a regular `img`, so give it an `alt` with the name of the person. Initials in the fallback are read as text.
- If the name is already next to the avatar, use `alt=""` so it is not read twice.
- `AvatarBadge` is silent unless you add `role="img"` and `aria-label`. Do not rely on its color alone.
