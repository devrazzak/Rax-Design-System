## Usage

```tsx
import { Container, Heading, Section } from '@rax-ds/ui';

export function Features() {
    return (
        <Section spacing="lg" tone="muted">
            <Container>
                <Heading as="h2">Features</Heading>
            </Container>
        </Section>
    );
}
```

A section adds vertical padding and a background. It does not limit the width, so put a [Container](/docs/components/container) inside it.

## Accessibility

- Section renders the tag you choose with `as`: `section`, `article`, `aside`, `header` or `footer`. Choose the one that matches the content.
- A `section` element is exposed as a landmark only when it has an accessible name, so pass `aria-label` or `aria-labelledby` when you want that.
- For `<main>` and `<nav>` use the native elements, because `as` does not include them.
