## Usage

```tsx
import { Checkbox, Field, FieldLabel } from '@rax-ds/ui';

export function TermsCheckbox() {
    return (
        <Field orientation="horizontal">
            <Checkbox id="terms" />
            <FieldLabel htmlFor="terms">Accept terms and conditions</FieldLabel>
        </Field>
    );
}
```

## Accessibility

- Built on the Radix Checkbox. It is a button with `role="checkbox"` and `aria-checked` (`true`, `false` or `mixed`).
- `Space` toggles it.
- Give it a label with `htmlFor` and `id`, or `aria-label`. Clicking the label toggles the checkbox.
- `aria-invalid` turns the border red.
