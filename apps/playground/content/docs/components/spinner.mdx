## Usage

```tsx
import { Spinner } from '@rax-ds/ui';

export function Loading() {
    return <Spinner label="Loading results" />;
}
```

For a button that is working, use the `loading` prop of [Button](/docs/components/button) instead of placing a spinner in it.

## Accessibility

- With a `label` the spinner has `role="status"` and the label is in screen-reader-only text.
- Without a `label` the spinner is decorative and gets `aria-hidden`. Use that inside elements that already expose their own busy state, like Button.
- The rotation is turned off when the user prefers reduced motion.
