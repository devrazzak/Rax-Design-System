## Usage

```tsx
import {
    AlertDialog,
    AlertDialogAction,
    AlertDialogCancel,
    AlertDialogContent,
    AlertDialogDescription,
    AlertDialogFooter,
    AlertDialogHeader,
    AlertDialogTitle,
    AlertDialogTrigger,
    Button,
} from '@rax-ds/ui';

export function DeleteOrder() {
    return (
        <AlertDialog>
            <AlertDialogTrigger asChild>
                <Button variant="destructive">Delete order</Button>
            </AlertDialogTrigger>
            <AlertDialogContent size="sm">
                <AlertDialogHeader>
                    <AlertDialogTitle>Delete this order?</AlertDialogTitle>
                    <AlertDialogDescription>This action cannot be undone.</AlertDialogDescription>
                </AlertDialogHeader>
                <AlertDialogFooter>
                    <AlertDialogCancel>Cancel</AlertDialogCancel>
                    <AlertDialogAction variant="destructive">Delete</AlertDialogAction>
                </AlertDialogFooter>
            </AlertDialogContent>
        </AlertDialog>
    );
}
```

An alert dialog interrupts the user to ask for a decision. For other content in a modal window, use [Dialog](/docs/components/dialog).

## Accessibility

- Built on the Radix Alert Dialog. The content has `role="alertdialog"`, and the title and the description are linked to it.
- Focus moves into the dialog on open and is kept inside it. The cancel button receives focus first, so a quick `Enter` does not confirm. Focus returns to the trigger on close.
- `Escape` closes the dialog. Unlike [Dialog](/docs/components/dialog), a click outside does not close it, and there is no close button, so the user must choose an answer.
- A title and a description are required.
