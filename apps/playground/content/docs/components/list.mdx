## Usage

```tsx
import { List, ListItem } from '@rax-ds/ui';

export function Steps() {
    return (
        <List as="ol">
            <ListItem>Create an account</ListItem>
            <ListItem>Verify your email</ListItem>
        </List>
    );
}
```

## Accessibility

- Renders a native `ul` or `ol` with `li` items, so screen readers announce the list and its length.
- With `marker="none"` the list gets `role="list"`, because Safari with VoiceOver stops reading a list as a list when its markers are removed.
- The icon of a `ListItem` is hidden from screen readers (`aria-hidden`), so it must not carry meaning that the text does not.
