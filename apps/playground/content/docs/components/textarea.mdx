## Accessibility

- Renders a native `<textarea>`, so keyboard and form behavior is the browser's.
- Give it an accessible name with a [Label](/docs/components/label) or `aria-label`.
- `aria-invalid` turns the border red. Pair it with an error message linked by `aria-describedby`.
