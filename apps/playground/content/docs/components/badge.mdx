## Usage

```tsx
import { Badge } from '@rax-ds/ui';

export function StatusBadge() {
    return <Badge variant="secondary">Shipped</Badge>;
}
```

A badge is a short status label. The text is uppercase and wide-spaced, so keep it to a word or two.

## Accessibility

- A plain badge is a `span` with text and adds no role. A screen reader reads it as part of the surrounding text.
- Do not rely on color alone for meaning. The text should say the status.
- With `asChild` the child keeps its own semantics, so a link is a link.
