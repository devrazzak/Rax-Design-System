## Usage

```tsx
import { ScrollArea, Text } from '@rax-ds/ui';

export function Notes() {
    return (
        <ScrollArea className="h-48 w-full max-w-sm rounded-md border border-border">
            <Text>Long content goes here.</Text>
        </ScrollArea>
    );
}
```

The area needs a height (or a width, for horizontal scrolling), otherwise it grows with its content and never scrolls.

## Accessibility

- Built on the Radix Scroll Area, which scrolls natively, so mouse wheel, touch and keyboard scrolling work as in any scrollable element.
- The viewport shows a focus outline when it receives focus.
