## Accessibility

- Activates with `Enter` and `Space`, like a native button.
- While `loading`, the button sets `aria-busy` and `aria-disabled` but stays focusable, so keyboard and screen reader users do not lose their place.
- Use a link (`asChild` with `<a>` or `<Link>`) when the button goes to another page, and a button when it does something on the page.
