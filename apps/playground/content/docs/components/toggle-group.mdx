## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from '@rax-ds/ui';

export function RangePicker() {
    return (
        <ToggleGroup type="single" defaultValue="week" aria-label="Range">
            <ToggleGroupItem value="day">Day</ToggleGroupItem>
            <ToggleGroupItem value="week">Week</ToggleGroupItem>
        </ToggleGroup>
    );
}
```

The group sets `variant` and `size` once, and every item follows.

## Accessibility

- Built on the Radix Toggle Group. The group has `role="group"`, so give it an `aria-label`.
- `Tab` moves focus into the group and the arrow keys move between items. `Space` and `Enter` toggle the focused item.
- An icon-only item needs `aria-label`.
