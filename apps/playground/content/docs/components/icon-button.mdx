## Usage

```tsx
import { SettingsIcon } from 'lucide-react';

import { IconButton } from '@rax-ds/ui';

export function SettingsButton() {
    return (
        <IconButton label="Settings">
            <SettingsIcon />
        </IconButton>
    );
}
```

IconButton is a [Button](/docs/components/button) that shows only an icon. It is a square of the same height as the Button of that size. It shows its label in a [Tooltip](/docs/components/tooltip), which brings its own provider, so no setup is needed.

## Accessibility

- `label` is required and becomes the `aria-label`, because an icon alone has no accessible name.
- The tooltip shows on hover and keyboard focus. The accessible name does not depend on it, so `tooltip={false}` keeps the name.
- Everything else behaves like [Button](/docs/components/button): `Enter` and `Space` activate it, and a loading button stays focusable.
