## Usage

```tsx
import { Input } from '@rax-ds/ui';

export function SearchInput() {
    return <Input placeholder="Search" aria-label="Search" />;
}
```

Always give an input an accessible name: a [Label](/docs/components/label) or [Field](/docs/components/field) with `htmlFor` and `id`, or `aria-label`. The input is full width by default.

## Accessibility

- Renders a native `<input>`, so all keyboard and form behavior is the browser's.
- `aria-invalid` turns the border red. Pair it with an error message linked by `aria-describedby`.
- Use [InputGroup](/docs/components/input-group) when the input needs an icon, text or a button beside it.

## API reference

All native `<input>` props are passed through, except the native `size`, which is replaced.
