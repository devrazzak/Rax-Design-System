## Usage

```tsx
import { Heading } from '@rax-ds/ui';

export function PageTitle() {
    return <Heading as="h1">Dashboard</Heading>;
}
```

For body copy use [Text](/docs/components/text). The size scales are also described in [Typography](/docs/foundations/typography).

## Accessibility

- Renders a real heading element (`h1` to `h6`), so screen reader users can navigate by heading.
- Pick the tag for the outline, one `h1` per page and no skipped levels, and use `size` to change only the look.
