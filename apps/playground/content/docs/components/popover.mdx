## Usage

```tsx
import { Button, Popover, PopoverContent, PopoverDescription, PopoverTrigger } from '@rax-ds/ui';

export function HelpPopover() {
    return (
        <Popover>
            <PopoverTrigger asChild>
                <Button variant="outline">Help</Button>
            </PopoverTrigger>
            <PopoverContent>
                <PopoverDescription>Orders placed before noon ship the same day.</PopoverDescription>
            </PopoverContent>
        </Popover>
    );
}
```

A popover is a floating panel that can hold interactive content. For a short text hint use [Tooltip](/docs/components/tooltip), and for a list of actions use [DropdownMenu](/docs/components/dropdown-menu).

## Accessibility

- Built on the Radix Popover. The trigger has `aria-expanded` and `aria-controls`, and the content has `role="dialog"`.
- `Enter` and `Space` on the trigger open the popover. `Escape` closes it, and so does a click outside. Focus moves into the popover on open and returns to the trigger on close.
- The popover is not modal by default, so the rest of the page stays usable.
- Unlike [Dialog](/docs/components/dialog), a title and a description are optional. `PopoverTitle` and `PopoverDescription` are plain elements and are not linked with ARIA attributes. If the popover needs a name, add `aria-label` to `PopoverContent`.
