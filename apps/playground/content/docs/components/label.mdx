## Usage

```tsx
import { Input, Label } from '@rax-ds/ui';

export function EmailInput() {
    return (
        <>
            <Label htmlFor="email">Email</Label>
            <Input id="email" type="email" />
        </>
    );
}
```

To add a hint and an error message, use [Field](/docs/components/field).

## Accessibility

- Built on the Radix Label, which renders a native `<label>`. Connect it to a control with `htmlFor` and the control's `id`.
- Clicking the label focuses or activates the control.
- The dimmed look follows the `peer-disabled` style, so it works only when the control is a previous sibling with the `peer` class. [Checkbox](/docs/components/checkbox), [Switch](/docs/components/switch) and [RadioGroup](/docs/components/radio-group) items have it.
