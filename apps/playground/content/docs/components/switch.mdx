## Usage

```tsx
import { Field, FieldLabel, Switch } from '@rax-ds/ui';

export function NotificationSwitch() {
    return (
        <Field orientation="horizontal">
            <Switch id="notifications" />
            <FieldLabel htmlFor="notifications">Email notifications</FieldLabel>
        </Field>
    );
}
```

## Accessibility

- Built on the Radix Switch. It is a button with `role="switch"` and `aria-checked`.
- `Space` and `Enter` toggle it.
- Give it a label with `htmlFor` and `id`, or `aria-label`. Clicking the label toggles the switch.
- `aria-invalid` adds a red border.
