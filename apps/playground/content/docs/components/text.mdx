## Usage

```tsx
import { Text } from '@rax-ds/ui';

export function Intro() {
    return <Text color="muted">Your latest orders appear here.</Text>;
}
```

For titles use [Heading](/docs/components/heading). The size scales are also described in [Typography](/docs/foundations/typography).

## Accessibility

- Renders a `p`, `span` or `div` and adds no role or aria attributes.
- Muted text uses a semantic color token. Check the contrast when you put it on a colored background.
