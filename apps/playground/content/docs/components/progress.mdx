## Usage

```tsx
import { Progress } from '@rax-ds/ui';

export function UploadProgress({ value }: { value: number }) {
    return <Progress value={value} aria-label="Upload progress" />;
}
```

The bar is full width. Use [Spinner](/docs/components/spinner) when you do not know how long the task takes.

## Accessibility

- Built on the Radix Progress, which renders `role="progressbar"` with `aria-valuemin`, `aria-valuemax` and `aria-valuenow`.
- Give it a name with `aria-label` or `aria-labelledby`, so users know what is progressing.
- Show the number as text too if it matters, as the bar alone is hard to read exactly.
