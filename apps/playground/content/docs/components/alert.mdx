## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from '@rax-ds/ui';

export function SavedAlert() {
    return (
        <Alert>
            <AlertTitle>Saved</AlertTitle>
            <AlertDescription>Your changes are saved automatically.</AlertDescription>
        </Alert>
    );
}
```

An alert is a message inline in the page. For a message that needs a decision, use [AlertDialog](/docs/components/alert-dialog).

## Accessibility

- The alert has `role="alert"`, so screen readers announce it when it appears. Use it for messages the user should hear about, not for static content that is always on the page.
- Do not rely on color alone. Say what happened in the title or the description, and use an icon if it helps.
- An icon-only action needs a label. [IconButton](/docs/components/icon-button) requires one.
