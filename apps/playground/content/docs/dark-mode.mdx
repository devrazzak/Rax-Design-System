## How it works

Dark mode follows the `dark` class on `<html>`, not the operating system setting. Every component reads its colors from tokens, and the tokens change under the dark theme.

| Method    | Example                    |
| --------- | -------------------------- |
| Class     | `<html class="dark">`      |
| Attribute | `<html data-theme="dark">` |

## Switch the theme

Add or remove the class from your own code:

```ts
document.documentElement.classList.toggle('dark');
```

## Avoid a flash on load

The server does not know the saved theme. Run a small script in `<head>`, before the page paints, so the page never shows the wrong theme first. It uses the saved choice, otherwise the system setting:

```tsx
const themeScript = `try{var t=localStorage.getItem('theme');if(t==='dark'||(!t&&matchMedia('(prefers-color-scheme: dark)').matches))document.documentElement.classList.add('dark')}catch(e){}`;

export default function RootLayout({ children }: { children: React.ReactNode }) {
    return (
        <html lang="en" suppressHydrationWarning>
            <head>
                <script dangerouslySetInnerHTML={{ __html: themeScript }} />
            </head>
            <body>{children}</body>
        </html>
    );
}
```

`suppressHydrationWarning` is needed because the script changes `<html>` before React hydrates.

## Use a theme library

Any library that sets the `dark` class works, for example [next-themes](https://github.com/pacocoursey/next-themes) with `attribute="class"`.
